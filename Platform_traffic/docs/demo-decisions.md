# 交互与产品决策

## 采集范围和频率

- 用户说「采集一次」时，默认采集 X、Instagram、TikTok 三个平台。
- 本地调度服务执行固定浏览器采集脚本，不调用 AI 模型。默认每小时覆盖三个平台，用户可在「自动采集设置」中自定义 15 分钟至 7 天的整数分钟间隔，或使用每小时、每 3 小时、每 6 小时、每天的快捷选项。
- 设置支持启停、立即执行、上次开始、上次成功、下次执行及各平台结果；设置保存到本地，重启保留。关闭看板不影响采集，电脑、本机服务和 Ego 浏览器需保持运行且登录可用。
- 暂停后已开始的采集仍完成；同一时刻只允许一轮，休眠后不追补多轮。每个帖子每小时仍只保留一份快照，小于一小时的间隔会更新该小时记录。「刷新」仅重新读取数据库。
- 单个平台失败时保存其他平台的成功结果，错误显示在设置内并记录日志。登录或验证码交由用户处理。旧的 Codex 定时任务保持暂停，避免重复执行。
- 局域网入口为只读，支持查看采集状态；修改设置和立即执行须使用本机地址。
- 未公开或无法确认的指标保留缺失值，不写成 0。

## 内容分类

- 每个社媒平台下提供「全部 / 图片 / 视频」二级分类，卡片累计值、趋势、可选帖子和明细使用同一分类。
- 切换分类时重新选取该分类的最近三条帖子，保留时间粒度、指标和发布日期范围。每个平台分别保留当前分类。
- 图片包含图片轮播；含视频的帖子计入视频。类型由实际媒体或明确的链接结构决定，未确认类型仅计入全部。
- 没有视频时显示「暂无视频帖子，发布并采集后将在这里显示视频流量」，不生成示例视频数据。

## 图片和原帖

- 趋势图例、单帖图表和帖子明细中的缩略图可以放大预览。
- 缩略图旁以原帖 URL 替换正文文案，点击 URL 在新标签页访问原帖。
- 预览支持关闭按钮、Esc、点击遮罩关闭，并保留原帖链接作为图片加载失败时的查看入口。
